# Embedded bridge

The bridge is the small Mixin bootstrap that starts GTNA and Programmed Circuit Card from the single `gtceu` container. Its canonical NeoForge source layout is the repository root `src/main/java` and `src/main/resources`, matching the NeoForge ModDevGradle template.

The intermediate bridge JAR is generated by the root `jar` task and is consumed by `buildMergedRelease`; generated JARs are not committed under `source/bridge`.
